## 1. Nixon et al., 2026: реальный измеритель мешка в миллиметрах

[Первичная статья](https://link.springer.com/article/10.1186/s12880-026-02220-7) описывает выбранный срединный сагиттальный T2 DICOM: локализатор оценивает наклон области, сегментатор выделяет мешок, линия пересекает маску и преобразуется в мм. Авторы сообщают внешний MAE 1,079 мм на 50 случаях RSNA; это их оценка конкретного метода и корпуса, не гарантия для нашего демо. Автоматический выбор срединного среза не закрыт. Переходные уровни, неполное поле и ошибки обнаружения осложняют последовательную нумерацию снизу вверх. Клинические обучающие данные доступны по запросу, открыто опубликованы веса и inference.

В [официальном HF-релизе](https://huggingface.co/akashnixon123/apdiameter007) на ревизии `ab09a126fc99eccd4ed24e66a17fd73378c69d1c` архив `spine_pipeline_release.zip` занимает 361 221 656 байт. Оглавление подтверждает два checkpoint, `code/run_pipeline.py`, README и requirements. Код сохраняет `measurements.csv` и JPEG с линиями; окружение README — Python 3.10, Ultralytics 8.2 и TensorFlow CPU 2.15.

Проверка текстового кода выявила обязательные доработки: при отсутствующем PixelSpacing подставляется 1 мм; row/column spacing усредняется; длина определяется числом пикселей скелета. Для косой линии и анизотропии нужен расчёт по физическим координатам. Дополнительно исправить пути к checkpoint в примере README и заменить слепую нумерацию на проверенное сопоставление. LICENSE/model card не обнаружены: права кода, весов и зависимостей фиксировать отдельно.

Это наиболее прямой новый кандидат на POC измерения AP мешка. Его 2D-сагиттальная маска не является готовой 3D-маской и не даёт автоматически площадь мешка на аксиальном срезе.

## 2. OLSIA: готовый индекс высоты диска

[Статья OLSIA](https://doi.org/10.1097/BRS.0000000000005462) и [сайт/плагин авторов](https://github.com/imedslab/spineslicer) описывают поясничную T2-сегментацию и дисковые оценки. Проверен архив [SlicerDeepLS.zip](https://github.com/imedslab/spineslicer/blob/main/plugin/SlicerDeepLS.zip), около 775 KB: `DeepLS.py` содержит `discHeightIndex`, `autoSegment` и `autoGrade`.

Код автоматически выбирает CPU/CUDA и загружает модели из [imedslab/lsmodels](https://github.com/imedslab/lsmodels): пять segmentation checkpoint примерно по 92,8 MB и один grading checkpoint около 19,5 MB. Файлы опубликованы; их исполнение не проверено. В вычислительном коде DHI строится из площадей и диаметров контуров диска и соседних тел; это отношение, а не мм. Grading отображает четыре класса Pfirrmann 2–5, класса 1 в опубликованном пути нет. Лицензия плагина/весов не обнаружена; открытая статья не разрешает автоматически копирование кода.

Для backend отделить вычисления от API `slicer`, сохранить 2D-контуры/выбранный срез и определить совместимость входа. DHI можно добавить отдельным полем; его нельзя переименовать в переднюю, среднюю или заднюю высоту диска.

Происхождение весов также ограничивает выбор: обучение в статье проведено на NFBC1966 (1500 участников), а публичными обозначены проверочные SPIDER/Mendeley. Эти pretrained weights не соответствуют строгому условию «все обучающие изображения открыты».

## 3. SpineReport: больше готовой морфометрии, чем следовало из прежнего описания

Проверка [measure_seg.py](https://github.com/ivadomed/SpineReport/blob/main/spinereport/utils/measure_seg.py) подтверждает уже реализованные функции:

- `measure_canal`: площадь, AP/RL размеры, характеристики сторон и асимметрии;
- `measure_foramens`, `compute_foramen_compression_ratio`: площади и относительные показатели отверстий;
- `measure_disc`: медианная толщина, объём, форма, признаки ядра и сигнала;
- сохранение CSV и иллюстраций.

Медианная толщина не заменяет три заданных радиологических высоты. В просмотренном модуле не найдено отдельного вычисления размеров грыжи/миграции. Маски spinal canal и вычисленные CSF-признаки не переименовывать в достоверный отдельный контур мешка. Код [LGPL-3.0](https://github.com/ivadomed/SpineReport/blob/main/LICENSE); интеграция остаётся адаптером с сохранением метода и исходной геометрии.

## 4. MATLAB: открытые измерительные алгоритмы на аксиальных изображениях

Релиз [zwd3hgr6gg v1](https://data.mendeley.com/datasets/zwd3hgr6gg/1), CC BY 4.0, содержит обработку границ, поиск девяти ориентиров и измерения AP/расстояний слева и справа. Вход авторской цепочки — сегментации составных T1/T2 axial изображений с несколькими структурами, включая мешок. Это готовый измерительный алгоритм, но не подтверждённый end-to-end инструмент для нового DICOM.

Сегментационная часть опубликована [отдельно](https://data.mendeley.com/datasets/8cp2cp7km8/2), GPLv3, с MATLAB 2018a+ и дополнительными библиотеками. Подходящий обученный SegNet checkpoint пока не подтверждён. Для Python можно исследовать перенос алгоритма измерений при соблюдении условий; TSS-маска канала не обеспечивает все его входные структуры.

Поиск охватывал GitLab.com, ETH GitLab, запросы lumbar MRI / morphometry / thecal sac / stenosis / herniation / dimensions и ссылки из первичных публикаций. Полноту интернета доказать нельзя. Корректный вывод: **среди проверенных публичных релизов пока не найден полный готовый lumbar-конвейер трёх размеров грыжи и миграции**. Работы с такой целью существуют; статья, базовые YOLO-веса и доступный код обучения не равны готовому патологическому checkpoint.

## Как меняется практический план

1. Готовый SpineReport первым проверять на TSS-артефактах: сопоставить его показатели с полями нашего backend и показать контуры/измерения.
2. Nixon release — следующий кандидат для отдельного AP мешка: сначала фиксировать права, затем воспроизвести baseline, исправить физическую геометрию/нумерацию и проверить на открытых выбранных T2-срезах. Сохранить исходный и адаптированный результат отдельно.
3. OLSIA — кандидат для DHI и дисковой дегенерации. Проверить права и отделимость вычислений от Slicer до переноса в backend.
4. Для размеров грыжи продолжить поиск подходящего полного релиза; собственную сегментацию/геометрию делать только после установленного пробела. Ручное уточнение контура — возможный режим демо, но не подмена автоматического детектора.

Открытые веса и открытые обучающие изображения — отдельные критерии. Nixon не обеспечивает публичный доступ ко всем обучающим данным; OLSIA обучался на закрытой NFBC1966. Если ограничение «исключительно открытые данные» распространяется на происхождение всех pretrained weights, эти кандидаты ему не удовлетворяют. Сейчас они остаются результатами исследования, не подключёнными зависимостями продукта.
